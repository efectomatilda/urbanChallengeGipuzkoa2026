# Datos

Este directorio contiene los archivos utilizados por MATILDA.AI.

## Regla de oro

No todos los archivos tienen la misma unidad de análisis ni el mismo periodo.

- Población: 01/01/2025.
- Pirámide: 2019.
- Seguridad: enero-junio 2025 y enero-junio 2026.
- GTFS: oferta programada del feed incluido.

Consulta [`../docs/sources.md`](../docs/sources.md) y [`../docs/limitations.md`](../docs/limitations.md)
antes de combinar fuentes.

`barrios_donostia.geojson.json` es GeoJSON válido aunque tenga extensión `.json`.
