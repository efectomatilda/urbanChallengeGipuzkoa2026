# Checklist antes de entregar

## Repositorio

- [ ] `main` contiene README y estructura visible.
- [ ] El juez no necesita cambiar de branch para encontrar el agente.
- [ ] No hay API keys, contraseñas o secretos.
- [ ] Los nombres de archivos del agente coinciden con los datos.
- [ ] La validación local funciona.

## Agente

- [ ] Preguntas cuantitativas usan `ejecutar_codigo`.
- [ ] El agente no inventa cifras.
- [ ] La respuesta distingue hecho/patrón/interpretación/limitación.
- [ ] Las preguntas no soportadas producen una negativa explicada.
- [ ] El agente indica periodo y unidad de análisis.

## Datos

- [ ] Cada fuente tiene procedencia.
- [ ] Se documentan periodos.
- [ ] Se documentan transformaciones.
- [ ] Se conservan los 3 registros espaciales sin asignar.
- [ ] Se documentan las limitaciones de seguridad.

## Demo

- [ ] Hay al menos 5 preguntas reales.
- [ ] Hay al menos 1 ejemplo de cálculo.
- [ ] Hay al menos 1 ejemplo de herramienta ejecutada.
- [ ] Hay al menos 1 ejemplo de pregunta no soportada.
- [ ] Las capturas muestran el resultado real del agente.

## Presentación

- [ ] README explica el proyecto en 30 segundos.
- [ ] Web enlazada.
- [ ] Resultados reproducibles.
- [ ] No se exageran conclusiones.
