# Alignment with Urban Challenge 2026

The official challenge describes five evaluation dimensions:

- 25% usefulness for understanding the urban problem;
- 25% quality of analysis, sources and traceability;
- 25% agent functionality and tool use;
- 15% clarity of answers and artefacts;
- 10% reliability, limits and human supervision.

MATILDA's submission evidence is organised accordingly:

| Criterion | Repository evidence |
|---|---|
| Urban usefulness | problem statement + methodology + next-data roadmap |
| Analysis/sources | source ledger + reproducible indicators + validation |
| Agent/tool use | Studio agent + tool-first system prompt + demo questions |
| Clarity/artifacts | README + web + demo script |
| Reliability/limits | limitations + unsupported-question tests + human-supervision guidance |

The goal is not to maximise documentation volume. The goal is to make the agent's actual
functionality and analytical reasoning easy for a judge to verify.
